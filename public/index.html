How the observer protects your existing systems
This separate service reads existing order files and Payclock exports, reads FedFish Central’s send history on this computer, and uses only GET on the local inventory endpoint. The timestamp view reuses Payclock’s report calculation functions and can request read-only timestamps from the clock. It has no order, email, payroll, inventory, clock-device, or source-file mutation routes; order history and payload inspection are read-only. Existing credentials are not loaded.
The service runs with your Windows account permissions; its read-only behavior is enforced by its implementation, not an operating-system sandbox. For stronger isolation, run it under a separate account with read-only source-folder access.
